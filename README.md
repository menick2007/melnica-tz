# ТЗ на разработку продукции — Фабрика «Мельница»

Онлайн-форма технического задания, которую заполняет клиент. Заменяет Excel-файл
«ТЗ на разработку продуктов»: те же четыре блока, но с подсказками, контролем
обязательных полей, выбором формы и пористости по фотографиям и загрузкой референсов.

**Адрес формы:** _(появится после включения GitHub Pages)_

## Что внутри

Один файл — `index.html`, 508 КБ. В нём уже лежит всё: шрифт TildaSans,
фотографии вариантов, стили и логика. Внешних запросов страница не делает,
работает и без интернета, если открыть файл локально.

| Файл | Назначение |
|---|---|
| `index.html` | Сама форма — это и есть сайт |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Блоки формы

1. **Клиент** — установочные данные, заполняются один раз на заявку. Внизу свёрнутая
   служебная секция «Заполняет менеджер Мельницы».
2. **Характеристика** — наименование, оборудование, режим выпечки, габариты
   и органолептика (цвет корки, пористость, надрезы, добавки, посыпка).
3. **Фото и референс** — три зоны загрузки и поле для ссылки на облачную папку.
4. **Хранение и упаковка** — сроки годности, условия, упаковка, количество в коробе.

Блоки 2–4 повторяются по кнопке «Добавить ещё изделие» — одна заявка на весь ассортимент.

## Куда приходят заявки

По умолчанию форма ничего никуда не отправляет: клиент нажимает «Отправить»,
получает готовый файл заявки и присылает его на info@fmill.ru.

Чтобы заявки приходили автоматически, найдите в `index.html` строку:

```js
const SUBMIT_URL = "";
```

и впишите адрес приёмника форм — Formspree, Getform, вебхук Битрикс24 или свой
endpoint. Форма отправит туда `POST` с телом в JSON: `{v, ts, client, manager, items}`.
Если отправка не удалась, форма всё равно отдаст клиенту файл заявки, чтобы данные
не потерялись.

> Репозиторий публичный, поэтому вписанный адрес виден всем. Для Formspree
> и подобных сервисов это нормально — их endpoint и рассчитан на публичность.
> Секретные токены сюда класть нельзя.

## Как обновить форму

Через веб-интерфейс GitHub: откройте `index.html` → карандаш → внесите правку →
Commit changes. Через минуту-две GitHub Pages подхватит новую версию.

Из командной строки:

```bash
git add index.html && git commit -m "Правка формы" && git push
```

## Заметки

- Страница закрыта от поисковиков (`<meta name="robots" content="noindex,nofollow">`).
  Если форму нужно индексировать — удалите эту строку из `<head>`.
- Черновик клиента сохраняется в `localStorage` его браузера и восстанавливается
  при возврате на страницу. На сервер ничего не уходит.
- Фотографии сжимаются в браузере до 1500 px по длинной стороне перед вложением.
